# The Rebuilder's Encyclopedia — Landing Page

Landing page for **The Rebuilder's Encyclopedia: From Flint to Foundry — The Complete Guide to Reconstructing Civilization**.

## About

21.5 million words. 1,439 topics. 46 chapters. 2,519 technical diagrams. 7 stages of civilization rebuild. The most comprehensive guide to reconstructing human knowledge ever assembled.

Published by **Peony River Ventures**.

## Deployment

This is a static site (HTML/CSS/JS) designed for deployment on **Cloudflare Pages** or any static hosting provider.

### Cloudflare Pages

1. Connect this repo to Cloudflare Pages
2. Build command: (none — static files)
3. Build output directory: `/` (root)
4. Deploy

### Local Development

```bash
# Any static file server works
python3 -m http.server 8080
```

## Structure

```
index.html   — Main landing page
style.css    — Styles (dark industrial theme)
script.js    — Minimal interactions (nav, animations, form)
```

## Design

- **Theme**: Dark, serious, industrial — not prepper-paranoid
- **Colors**: Charcoal/slate background, rust/amber/copper accents
- **Typography**: EB Garamond (serif headings/body), Inter (UI), JetBrains Mono (labels)
- **Responsive**: Mobile-first, works on all screen sizes
